Design your folder structure

0 / 3 ▾

Claude Code works best when it understands your world. By organizing projects by type, each folder gets its own CLAUDE.md — a file that tells Claude the specific context for that kind of work. Apps get coding instructions. Documents get your style guides. It's like giving Claude a different expert hat for each folder.

/AI ← your root
  /apps Web apps, APIs, full-stack
  /problemsolving Analysis, data, research
  /doc_creation PDFs, decks, reports
  /context_creation Prompts, CLAUDE.md files
  /readings Book notes, summaries
  /beliefs Mental models, principles
  /career Resume, career docs
📁 Create these folders using your file manager. Open Finder (Mac), File Explorer (Windows), or your file manager of choice. Navigate to where you keep projects (Documents, Desktop, etc.) and create the folders shown above.

Subscribe and install Claude Code

0 / 4 ▾

Head to claude.ai and sign up for a Claude Pro subscription. Once you're in, Claude will nudge you to install Claude Code — follow that flow. The easiest way to get it running is through VS Code: just install the extension and you're good to go.

⚡ Why Pro? Claude Code requires a Claude Pro (or Max) subscription. This unlocks the full power of Claude directly on your machine — not just chat in a browser, but an AI that can read your files, run commands, and build things for you.
i VS Code makes this easy. Instead of installing via the terminal, we'll use the Claude Code extension for VS Code. It handles all the setup for you — no commands to memorize, no PATH issues, just install and go.
  • ✓ Go to claude.ai and subscribe to Claude ProCreate an account if you don't have one, then upgrade to Pro
  • ✓ Download and install VS CodeSkip this if you already have VS Code installed
  • ✓ Install the Claude Code extension in VS CodeOpen VS Code → Extensions sidebar (⌘⇧X on Mac, Ctrl+Shift+X on Windows) → search “Claude Code” → Install

Superpower

Install Wispr Flow for voice dictation

0 / 3 ▾

Typing prompts is fine, but talking to Claude is transformative. Wispr Flow lets you dictate anywhere your cursor is — including inside the terminal. In the next step, Claude will interview you to create your style guides. Dictating your answers feels natural, and the output is richer because you speak more freely than you type.

🎤 Why voice matters here: When Claude interviews you about your visual style and writing tone, the best answers are conversational. Dictation removes the friction between thinking and expressing. You'll be surprised how much better the style guides turn out when you just talk.
i Wispr Flow is a system-wide dictation tool. It works in any text field — terminal, browser, documents. Hold the activation key, speak, and your words appear as text.
  • ✓ Download and install Wispr FlowVisit wispr.flow and follow the installer for your OS
  • ✓ Grant microphone permissions when promptedWispr needs mic access to transcribe your voice
  • ✓ Test it: hold the activation key and speak a sentenceTry it in any text field — your words should appear as you talk

Create your style guides with Claude

0 / 4 ▾

Here's where the magic starts. Instead of writing style guides yourself, you'll have Claude interview you and create them. This is the fundamental pattern: describe what you want, let Claude ask clarifying questions, iterate until it's right. Once you have these two files, every document Claude creates will look and sound like you.

★ This is your first real Claude exercise! Notice how Claude asks follow-up questions, adapts to your answers, and produces a structured document. This is the pattern you'll use for everything.
Example prompt — visual identity "Help me create a visual-identity.md file. Ask me questions about my color preferences, fonts I like, and the overall aesthetic I'm going for. Then write the file."
Example prompt — writing style "Now help me create a writing-style.md. Interview me about my preferred tone, how formal I write, words I avoid, and how I structure documents. Then write the file."
  • ✓ Open your terminal and navigate to your AI folder, then type claudeMac: open Terminal. Windows: open PowerShell. Then navigate to your AI folder.
  • ✓ Ask Claude to help create your visual-identity.mdUse the example prompt above — let Claude interview you about colors, fonts, and aesthetic
  • ✓ Ask Claude to help create your writing-style.mdSame approach — let Claude ask about tone, formality, structure, and words you avoid
  • ✓ Review both files and reference them in your CLAUDE.mdAdd file paths under a ## Style Guidelines section so all projects inherit them

Prepare

Pull source material into your project

0 / 3 ▾

AI output is only as good as the context you give it. By dropping your reference documents into a project folder, Claude can read, synthesize, and build on real material — not hallucinate from thin air. Better input equals dramatically better output.

⚡ Why context matters: Claude reads every file in your project. The more relevant material you give it, the more accurate, specific, and useful its output becomes. Think of source documents as Claude's research library.
AI / doc_creation /
  my-first-pdf /

📁 Use your file manager for this step. Navigate to doc_creation inside your AI folder. Create a new folder called my-first-pdf, and inside that, create a sources folder. Then drag your reference documents into it.
  • ✓ Create a my-first-pdf folder with a sources subfolderInside AI → doc_creation
  • ✓ Drag at least one reference document into sourcesPDF, Word doc, notes — anything with content you want in the output
  • ✓ Open your terminal, navigate to my-first-pdf, and type claudeMac: Terminal. Windows: PowerShell.
